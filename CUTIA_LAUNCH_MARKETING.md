# Cutia — Lançamento

**29 de junho de 2026 | v1.0 PT-BR | Pronto para Produção**

---

## O Que é Cutia?

Cutia é ChatGPT/Claude rodando no seu computador. Seus dados, seus modelos, sua segurança.

Versão em português do [Odysseus](https://github.com/pewdiepie-archdaemon/odysseus).

---

## Começar Agora

### Windows (PowerShell)
```powershell
git clone --branch feature/pt-br-translation https://github.com/FinweeJur/odysseus.git
cd odysseus
.\install-ptbr.ps1
```

### Linux/Mac (Bash)
```bash
git clone --branch feature/pt-br-translation https://github.com/FinweeJur/odysseus.git
cd odysseus
chmod +x install-ptbr.sh && ./install-ptbr.sh
```

**Acesse:** `http://127.0.0.1:7000`

## O Que Você Consegue Fazer

✅ **Chat com IA Local**  
Qualquer modelo (Ollama, OpenAI, Claude, etc.)

✅ **Agentes Autônomos**  
IA executa tarefas com acesso a arquivos, web, terminal

✅ **Documentos**  
Editor com IA integrada (Markdown, HTML, CSV)

✅ **E-mail Inteligente**  
Triagem automática, rascunhos sugeridos, sincronização calendário

✅ **Calendário Sincronizado**  
CalDAV: Apple Calendar, Google Calendar, Nextcloud

✅ **Tarefas com Lembretes**  
Agendamento, notificações, integração com agentes

✅ **Pesquisa Profunda**  
IA pesquisa e sintetiza relatórios automaticamente

✅ **Memória Persistente**  
IA aprende e usa seu conhecimento em futuras conversas

## Por Que Cutia?

**Privacidade Total**
- Roda 100% no seu computador
- Dados nunca saem de casa
- Sem telemetria, sem rastreamento

**Você Escolhe**
- Qual modelo de IA
- Qual provedor (local ou API)
- Como configurar tudo

**Potência Real**
- Agentes executam tarefas sozinhos
- Integração com ferramentas reais
- Suporte a MCP (Model Context Protocol)

**Código Aberto**
- MIT License
- Totalmente modificável
- Comunidade ativa

## Requisitos Mínimos

- Python 3.11+
- 8GB RAM (16GB ideal)
- 50GB disco
- GPU opcional (NVIDIA/AMD)

**Recomendado:** Instale [Ollama](https://ollama.ai) para rodar modelos localmente
