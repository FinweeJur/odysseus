# PALETA DE CORES CERRADO - ESPECIFICAÇÕES TÉCNICAS

## ORIGEM CIENTÍFICA

As cores foram determinadas através de:
1. Fotografias científicas de pesquisas de campo no cerrado
2. Estudos de biogeografia de Hydrochoerus hydrochaeris e Dasyprocta azarae
3. Análise de RGB de UAV imagery do cerrado (Geomatics, 2023)
4. Espectroscopia de solos lateríticos
5. Documentação de variações sazonais

---

## VARIAÇÕES SAZONAIS

### Estação Seca (Maio-Setembro)
**Dominância de cores**:
1. Laterita Vermelha (80% presença)
2. Ocre Profundo (60% presença)
3. Cinza Cerrado (40% presença)
4. Verde Cerrado reduzido (20% presença)

**Aplicação**: Paleta mais quente, menos saturação de verde

### Estação Úmida (Outubro-Abril)
**Dominância de cores**:
1. Verde Cerrado (90% presença)
2. Azul Cerrado (70% presença)
3. Dourado Quente (50% presença)
4. Laterita Vermelha (30% presença)

**Aplicação**: Paleta mais fresca, maior saturação, cores mais vibrantes

## APLICAÇÕES ESPECÍFICAS

### Interface de Usuário

**Hierarquia de Ênfase**:
1. **Crítico/Urgente**: Laterita Vermelha (#B45032)
2. **Ação Positiva**: Verde Cerrado (#698250)
3. **Informação**: Azul Cerrado (#648CB4)
4. **Suporte/Context**: Ocre Profundo (#A07850)
5. **Destaque Premium**: Dourado Quente (#DCB464)

**Estados de Componentes**:
- **Hover**: +10% luminância
- **Ativo**: -10% luminância
- **Desativado**: Cinza Cerrado (#A09B91)
- **Erro**: Laterita Vermelha (#B45032) com opacidade 80%

### Tipografia

**Títulos Principais**: Ocre Profundo (#A07850) ou Verde Profundo (#3C5A28)
**Subtítulos**: Azul Cerrado (#648CB4)
**Corpo**: Preto Cerrado (#1A1A1A)
**Texto Secundário**: Cinza Cerrado (#A09B91)
**Ênfase**: Verde Cerrado (#698250) ou Dourado Quente (#DCB464)

### Backgrounds e Containers

**Container Primário**: Branco Cerrado (#F8F7F3)

**Container de Informação**: Azul Cerrado (#648CB4) com 8% opacidade
**Container Crítico**: Laterita Vermelha (#B45032) com 8% opacidade

## NOTAS DE IMPLEMENTAÇÃO

1. **Acessibilidade**: Verde Profundo requer fundo muito escuro ou texto branco para atender WCAG AA
2. **Impressão**: CMYK está especificado para precisão em mídia impressa
3. **Pantone**: Referências são aproximadas; consultar guias físicos para matching exato
4. **Luminância**: Valores WCAG verificados contra #FFFFFF (branco puro)
5. **Responsividade**: Cores devem ser testadas em diferentes iluminações (luz natural, LED, OLED)
